# 🚀 Smart Complaint Management System

An AI-powered Complaint Management System built using the MERN Stack to simplify complaint registration, tracking, and resolution through an intuitive web interface.

## 🌟 Features

- 🔐 Secure User Authentication (JWT)
- 📝 Register and Track Complaints
- 👨‍💼 Admin Dashboard
- 📊 Complaint Analytics
- 🤖 AI-Assisted Complaint Handling
- 📱 Responsive User Interface
- 🔍 Search & Filter Complaints
- 📂 Complaint Status Management
- ☁️ Cloud Deployment

## 🚀 Installation

### Clone Repository

```bash
git clone https://github.com/Akarshi27/Smart-Complaint-Management-System.git
```

### Backend

```bash
cd backend
npm install
npm run dev
```

### Frontend

```bash
cd frontend
npm install
npm run dev
```
